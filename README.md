# Antonio Digital

Marketing site for Antonio Digital: web design, SEO, maintenance and hosting
for small businesses in Šibenik and across Croatia.

- **Croatian is the primary language**, served at the site root (`/`).
- **English** is secondary and will be served under `/en/` once translated.

## How it's built

Static site generated by `build.py`. Each page lives in
`src/pages/<page-id>/<lang>/` as a `meta.json` + `content.html` pair. Shared
chrome (header, footer, base template) lives in `src/partials/`. Global styles
are in `styles.css`, scripts in `script.js`.

```bash
python build.py      # regenerate all HTML + sitemap.xml
```

Run `build.py` after editing any partial or page content. The generated
`index.html` files, `sitemap.xml` and assets are what gets deployed.

## Local preview

```bash
python -m http.server 8099
# open http://127.0.0.1:8099/
```

## Deploy

Hosted on Vercel, auto-deploying from the `main` branch on GitHub.
